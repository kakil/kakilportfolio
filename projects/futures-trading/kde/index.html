Kit Decision Engine

KDE is a decision-support indicator built to make market state, directional authority, balance, structure, value, continuation, risk, and execution context easier to read consistently. It does not replace the Trading OS and it is not an autonomous trade signal.

Known-good baseline: KDE v6.3.26. The current development branch is testing a separate READY-permission lifecycle change; it is not part of the frozen public baseline yet.
State

Market classification

Campaign, Trend, Intraday Flow, Balance/Transition, directional authority, EQ behavior, session context, and continuation state are surfaced in one decision layer.

Structure

Context & control

KDE tracks 1m/5m/15m/HTF EMA relationships, VWAP, protected structure, decision zones, liquidity references, swing/internal structure, and market-state conflicts.

Execution

Permission, not prediction

Lower-timeframe evidence is used to determine when a valid setup has actually reached executable conditions rather than merely looking directional.

Setup tracker

A ten-step evidence sequence.

The current tracker organizes the setup through Location, Reaction, 5m Displacement, 5m CHoCH, 5m BOS, Authority, 1m VALUE, 1m REASSERT, Risk/Runway, and READY. The tracker is designed to make the reasoning visible without granting independent authority over the chart.

Current engineering

READY should be permission, not a stale badge.

The next controlled change is testing a finite READY lifecycle so a completed execution sequence cannot remain active indefinitely after the original lower-timeframe opportunity has gone stale. That work is deliberately isolated from market-state, Balance, authority, and management logic.

Development discipline

One change, one regression gate, one known-good baseline.

KDE changes are versioned separately, compiled in TradingView, tested against protected behavior, documented with evidence, and frozen before another state-machine change begins. Failed compiler/runtime attempts remain in the development record rather than being erased.
